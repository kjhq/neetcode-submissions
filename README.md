## what is this

[neetcode.io](https://neetcode.io) is a coding interview prep platform: curated problems, video solutions and an in-browser editor. every solution i submit there gets committed here by neetcode's github integration, so this repo doubles as a log of my data structures & algorithms practice.

---

## layout

files are written by the sync, so the layout follows neetcode's convention:

```
<topic>/<problem-slug>/submission-<n>.<ext>
```

for example:

```
Data Structures & Algorithms/two-integer-sum/submission-1.py
Data Structures & Algorithms/design-hashmap/submission-0.cpp
```

`submission-<n>` is the attempt number on neetcode, so a problem can have more than one file.

---

## how sync works

1. github is connected at [neetcode.io/profile/github](https://neetcode.io/profile/github)
2. each submission is auto-committed (configurable by status)
3. past solutions can be pushed with a bulk sync, or one by one from submission history

> the folders are managed by the sync. solutions are written on neetcode, not edited here.
