## what is this

[neetcode.io](https://neetcode.io) coding interview prep — curated problems, video solutions, in-browser editor. this repo holds accepted solutions synced from my account.

---

## how sync works

1. connect github at [neetcode.io/profile/github](https://neetcode.io/profile/github)
2. auto-commit on each submission (configurable by status)
3. bulk sync — push all past solutions from settings
4. manual sync — per-problem from submission history
